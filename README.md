# Butaca

Plataforma de cinema amb pel·lícules, actors, cinemes i cartellera de Catalunya.

## Desenvolupament

Aquest projecte està desenvolupat amb Angular.

### Instal·lar les dependències

```bash
npm install
```

### Iniciar el servidor de desenvolupament

```bash
ng serve
```

Després, obre el navegador a http://localhost:4200/. Els canvis als fitxers es reflectiran automàticament.

### Generar components

```bash
ng generate component nom-component
```

### Compilar el projecte

```bash
ng build
```

Els fitxers compilats es generen a la carpeta `dist/`.

## Tecnologies

- Angular
- TypeScript
- HTML
- CSS
